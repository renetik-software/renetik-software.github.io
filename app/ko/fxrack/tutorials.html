    FXRack 튜토리얼

    FXRack 가이드

    FXRack을 사용하여 오디오를 녹음하고, 이펙트 체인을 구축하고, 샘플을 편집하고, 클립을 루프하고, 오디오를 내보내고, MIDI 장비나 다른 음악 앱에서 앱을 제어하세요.

    빠른 시작

    1. FXRack을 엽니다.
    2. Session 컨트롤에서 세션 프리셋을 선택하거나 Clear에서 시작합니다.
    3. Device, Record, File, Library 또는 Paste에서 입력 소스를 선택합니다.
    4. 클립을 녹음, 가져오기 또는 메인 랙에 로드합니다.
    5. Pre Fader FX, 트랙 레벨, Post Fader FX 및 마스터 레벨을 조절합니다.
    6. 앱 샘플러, 내보내기, 설정, MIDI, 테마, 오디오 패닉 또는 종료가 필요할 때 사이드 패널을 사용합니다.

    랙 세션 선택

    세션 프리셋은 전체 랙 설정을 불러옵니다. 기본 제공 세션에는 Podcast Clean, Rock Guitar, Ambient Echo, Vocal Warmth, Studio Magic, Live Performance, Drum Room, Electric Energy, Acoustic Serenity, Synth Dreams, Bass Booster, Vocal Clarity, Guitar Crunch, Orchestral Touch, Mastering Suite가 포함됩니다.

    불러온 세션을 변경하면 FXRack은 현재 랙이 저장된 프리셋과 더 이상 정확히 일치하지 않음을 나타내기 위해 수정됨으로 표시합니다.

    입력 선택 또는 녹음

    입력(Input) 선택기는 오디오가 랙으로 들어오는 곳입니다.

    1. 입력을 탭합니다.
    2. 라이브 마이크 또는 인터페이스 입력에 대한 디바이스를 선택합니다.
    3. 녹음을 선택하여 메인 트랙 녹음기를 엽니다.
    4. 파일을 선택하여 Android 파일 피커를 통해 미디어를 가져옵니다.
    5. 라이브러리를 선택하여 저장된 앱 샘플을 불러옵니다.
    6. 클립보드 샘플을 사용할 수 있을 때 붙여넣기를 선택합니다.

    디바이스 입력은 내장 마이크의 경우 Off, Stereo 또는 Left일 수 있습니다. 모니터링 볼륨과 음소거는 시각적인 입력 미터링과 별개이므로, 레벨을 계속 확인하면서 모니터링을 음소거할 수 있습니다.

    메인 트랙 녹음기는 입력 리미터, 입력 레벨, 입력 음소거, 채널 선택, 입력 이펙트 프리셋, 레이턴시 보정, 녹음, 오버더브, 수락 및 되돌리기를 지원합니다. 녹음된 오디오를 재생과 일치시켜야 할 때 레이턴시 보정을 사용하세요.

    클립 재생 및 라우팅

    로드된 클립은 메인 랙에 파형으로 표시됩니다. 재생 및 테이크 확인을 위해 파형 영역을 사용한 다음, 그 주변의 트랙 및 마스터 레벨을 조절하세요.

    우측 툴바에는 싱크 시간 및 BPM 제어 기능이 있습니다. 또한 설정 패널에서는 자동 및 내장 스피커와 같은 명시적 출력을 포함하여 패닝 및 출력 디바이스를 선택할 수 있습니다.

    샘플 편집

    상세한 편집이 필요한 경우 샘플 편집기에서 클립을 엽니다.

    1. 파형을 사용하여 확대/축소 및 스크롤합니다.
    2. Position, Start, Offset 및 End 마커를 설정합니다.
    3. 클립이 박자와 마디 타이밍을 사용해야 할 때 BPM을 할당합니다.
    4. BPM을 알고 있을 때 마커 표시를 Beat와 Time 사이로 전환합니다.
    5. 샘플을 다시 시작하거나 반복해야 할 때 Restart 또는 Loop를 활성화합니다.
    6. ADSR을 열어 어택, 디케이, 서스테인, 릴리즈 및 루프 전환을 조절합니다.

    또한 편집기는 지우기, 녹음, 열기, 복사, 붙여넣기, 내보내기, 클립 레벨 FX, 렌더 앤 리플레이스 워크플로우를 지원합니다.

    가져오기, 라이브러리 및 클립보드

    파일 입력은 Android 파일 피커를 엽니다. FXRack은 가져오기 진행 상황을 표시하면서 지원되는 오디오를 로드하고 비디오 파일에서 오디오를 추출할 수 있습니다.

    라이브러리를 사용하여 저장된 앱 샘플을 선택하거나 더 이상 필요 없는 샘플을 제거하세요. 샘플 편집기에서 복사를 사용하여 샘플을 앱 클립보드에 배치한 다음, 붙여넣기를 사용하여 다른 호환되는 타겟에 로드하세요.

    이펙트 체인 구축

    메인 랙에는 Pre Fader FX 및 Post Fader FX 섹션이 있습니다. 각 섹션에는 5개의 가시적인 이펙트 슬롯이 표시됩니다.

    1. 빈 이펙트 슬롯을 탭합니다.
    2. Filter, EQ3, EQ7, Reverb Simple, Reverb Standard, Reverb Pro, Delay, Distortion, Noise Gate, Compressor, Limiter 또는 Chorus를 선택합니다.
    3. 이펙트 프리셋을 선택합니다.
    4. 이펙트 파라미터를 직접 조절합니다.
    5. 설정된 이펙트 슬롯을 길게 눌러 Off로 지웁니다.

    이펙트 편집기는 대형 파라미터 컨트롤, 활성화 상태, 프리셋 선택 및 가능한 경우 미터를 제공합니다. 딜레이는 박자 동기화 타이밍 또는 밀리초 타이밍을 사용할 수 있고, 디스토션은 타입 선택 기능이 있으며, 리미터는 룩어헤드 선택 기능이 있습니다.

    클립 이펙트 렌더링

    샘플 편집기 FX는 클립 레벨 이펙트입니다. 활성화된 이펙트를 오디오 파일에 직접 기록하려면 Render and Replace를 사용하세요. FXRack은 오디오를 교체하기 전에 확인을 요청한 다음 렌더링된 파형이 로드된 상태로 유지합니다.

    앱 샘플러 및 내보내기 사용

    앱 샘플러를 위해 사이드 패널을 엽니다. 여기에는 메인 트랙 녹음기와 별개인 녹음, 편집, 라이브러리 및 내보내기 워크플로우가 있습니다.

    내보내기 탭에서는 샘플러 오디오를 내보내기 전에 오디오 포맷과 비트레이트를 선택할 수 있습니다.

    MIDI로 FXRack 제어

    외장 MIDI 컨트롤러로 FXRack을 제어해야 할 때 Settings에서 Control을 사용하세요.

    1. 제어 프리셋을 선택합니다.
    2. MIDI 입력 장치를 선택합니다.
    3. Application, FX, Mix 또는 Controller 같은 매핑 섹션을 엽니다.
    4. 매핑을 활성화하고 채널, 유형, 인덱스 또는 값을 선택합니다.
    5. Learn을 사용하여 들어오는 MIDI 이벤트를 캡처합니다.
    6. Test를 사용하여 매핑을 확인합니다.

    Application 매핑에는 Audio panic, BPM Increment, BPM Decrement, Metronome Volume, Preset Next, Preset Previous, Sampler Record Toggle 및 Start/Stop Toggle이 포함됩니다.

    MIDI 출력과 동기화

    FXRack이 다른 앱이나 MIDI 장치로 타이밍을 보내야 할 때 Settings의 Sync를 사용합니다. 출력 장치와 채널을 선택한 후 필요에 따라 Clock Sync, Transport Start and Stop, Metronome Notes를 활성화하세요.

    설정 사용자 지정

    Settings에는 Performance, Control, Sync, Language, Data/Storage 및 Musical Mode가 포함됩니다.

    • Performance는 Max Compatibility, Medium Performance, Max Performance 및 Manual 모드를 제공합니다.
    • Manual 성능 설정에는 오디오 출력, 오디오 입력, 앱 상태 재설정이 포함됩니다.
    • 오디오 출력 설정에는 성능 모드, 버퍼 크기, 출력 공유, 샘플 레이트가 포함됩니다.
    • 오디오 입력 설정에는 성능 모드, 프리셋, 버퍼 크기, 입력 공유, 프로세싱 모드가 포함됩니다.
    • Data/Storage는 내보내기, 가져오기, 오디오 저장 형식 환경설정을 지원합니다.
    • Musical Mode는 Beats와 Bars 사이를 전환하고 박자표를 설정합니다.

    테마 선택 항목으로는 System, Light, Dark, Blue light, Blue, Gold, Wood, Pastel Light, Sepia가 있습니다.

    알림 제어 사용

    재생이나 녹음이 활성화되면 Android에 포그라운드 알림이 표시될 수 있습니다. FXRack 알림 제어에는 재생/메트로놈 토글, 마스터 음소거, 녹음, 종료가 포함됩니다. 알림 제목은 현재 세션 프리셋을 따릅니다.
