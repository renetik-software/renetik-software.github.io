    Metronome 튜토리얼

    Metronome 가이드

    연습을 위한 안정적인 템포, 공연을 위한 커스텀 리듬 클릭, 또는 다른 음악 앱 및 기기와 MIDI 싱크가 필요할 때 Metronome을 사용하세요.

    빠른 시작

    1. Metronome을 엽니다.
    2. 왼쪽의 큰 BPM 컨트롤로 템포를 설정합니다.
    3. 중앙의 큰 재생 버튼을 눌러 시작합니다.
    4. 오른쪽의 수직 레벨 컨트롤로 볼륨을 조절합니다.
    5. 완료되면 중앙의 정지 버튼을 누릅니다.

    템포 설정

    메인 화면에서는 연주하는 동안 템포 컨트롤이 계속 표시됩니다.

    • 왼쪽 BPM 선택기를 사용하여 템포를 높이거나 낮춥니다.
    • 재생 버튼 아래의 큰 BPM 수치를 탭하여 탭 BPM을 엽니다.
    • 템포 변경은 재생 중에도 수행할 수 있습니다.

    BPM 탭하기

    탭 BPM은 노래나 리허설에서 이미 템포가 느껴질 때 유용합니다.

    1. 메인 화면에서 BPM 숫자를 탭합니다.
    2. 박자에 맞춰 대화상자의 중앙을 탭합니다.
    3. 충분히 탭한 후, 앱에 계산된 BPM이 표시됩니다.
    4. 적용하려면 [확인]을 누르고, 기존 템포를 유지하려면 [취소]를 누릅니다.

    탭 사이의 간격이 너무 길어지면 앱이 측정을 다시 시작합니다.

    재생 및 볼륨 제어

    중앙 버튼은 Metronome을 시작하고 정지합니다. 재생 중에는 무대나 연습 중에 쉽게 찾을 수 있도록 버튼이 정지 상태로 바뀝니다.

    오른쪽 레벨 컨트롤을 사용하여 Metronome 볼륨을 설정하세요. 레벨 컨트롤에는 출력 피드백과 현재 dB 값이 표시됩니다. 소리를 즉시 멈춰야 하는 경우 사이드 패널을 열고 오디오 패닉을 사용하세요.

    리듬 프리셋 선택

    프리셋을 사용하면 단순한 비트뿐만 아니라 음악적인 클릭 패턴으로 Metronome을 재생할 수 있습니다.

    1. 메인 화면에서 프리셋 영역을 엽니다.
    2. 내장 프리셋 또는 저장된 사용자 프리셋을 둘러봅니다.
    3. 닫힌 하이햇 및 마라카스, 드럼 및 햇, 하이햇, 우드블록, 사각형 및 메트로놈, 또는 메트로놈 클릭과 같은 프리셋을 선택합니다.
    4. 편집한 버전을 사용자 프리셋으로 유지하려면 저장을 누릅니다.

    악기 및 사운드폰트 선택

    프리셋 툴바에는 악기 선택기가 포함되어 있습니다. 이를 사용하여 현재 리듬에서 사용할 사운드를 선택하세요.

    • 기본 악기에서 Studio Drums를 사용할 수 있습니다.
    • 검색을 사용하여 악기를 더 빠르게 찾으세요.
    • 커스텀 사운드가 필요할 때 SoundFont 파일을 가져옵니다.
    • 저장하기 전에 가져온 SoundFont 악기를 카테고리에 할당합니다.
    • 다운로드 가능한 사운드 팩을 둘러보려면 스토어를 엽니다.

    스토어에는 스탠다드/재즈 킷, 일렉트로닉 킷, 파워 킷, 에스닉 킷, 머신 킷, FX 킷 등의 카테고리가 포함되어 있습니다.

    리듬 시퀀스 편집

    리듬 프리셋의 실제 노트를 변경하려면 시퀀스 편집기를 사용하세요.

    1. 프리셋을 엽니다.
    2. 변경할 프리셋을 선택합니다.
    3. 편집을 누릅니다.
    4. 그리드를 사용하여 노트나 레인을 선택합니다.
    5. 편집된 리듬을 미리 들어봅니다.
    6. 준비되면 사용자 프리셋으로 저장합니다.

    편집기는 드럼 맵 레인과 노트 이름 레인을 지원합니다. 그리드에 음악적 위치가 표시되므로 원하는 위치에 정확하게 노트를 배치할 수 있습니다.

    선택한 노트 편집

    노트를 선택한 후 다음 편집 작업을 사용하세요.

    • 복사(Copy): 노트를 복제합니다.
    • 제거(Remove): 노트를 삭제합니다.
    • 이동(Move): 선택한 노트를 이동합니다.
    • 크기 조절(Resize): 노트 길이를 변경합니다.
    • 음량(Loudness): 노트 볼륨을 변경합니다.
    • 퀀타이즈(Quantize): 타이밍 그리드에 노트를 맞춥니다.

    퀀타이즈 값에는 1/32, 1/16, 1/8, 1/4, 1/2 및 1박자가 포함됩니다.

    MIDI와 동기화

    Metronome이 다른 앱이나 MIDI 장치를 제어해야 할 때 동기화를 사용하세요.

    1. 측면 패널을 엽니다.
    2. 동기화를 선택합니다.
    3. MIDI 출력 장치를 선택합니다.
    4. MIDI 채널을 선택합니다.
    5. 필요한 동기화 옵션을 활성화합니다.

    사용 가능한 동기화 옵션에는 클럭 동기화, 트랜스포트 시작 및 중지, Metronome 노트가 포함됩니다. 클럭과 트랜스포트는 독립적으로 활성화할 수 있습니다.

    MIDI로 앱 제어

    외부 장치로 Metronome을 제어해야 할 때 MIDI 제어를 사용하세요.

    1. 측면 패널을 엽니다.
    2. 제어를 선택합니다.
    3. 입력 장치를 선택합니다.
    4. 매핑을 선택합니다.
    5. 활성화하고 채널, 유형, 값을 설정합니다.
    6. 학습(Learn)을 사용하여 들어오는 MIDI 이벤트를 캡처합니다.
    7. 테스트(Test)를 사용하여 매핑을 확인합니다.

    유용한 매핑에는 오디오 패닉, BPM 감소, BPM 증가, 다음 프리셋, 이전 프리셋, 시작/정지 토글, 볼륨이 포함됩니다.

    외관 및 설정 사용자 지정

    테마나 설정을 변경하려면 측면 패널을 엽니다.

    테마에는 시스템, 라이트, 다크, 블루 라이트, 블루, 골드, 우드, 파스텔 라이트, 세피아가 포함됩니다.

    설정에는 성능, 제어, 동기화, 언어, 데이터/저장소, 음악 모드가 포함됩니다.

    • 성능에서는 튜닝 프리셋 또는 수동 오디오 출력 설정을 선택할 수 있습니다.
    • 오디오 출력 설정에는 성능 모드, 버퍼 크기, 출력 공유, 샘플 레이트가 포함됩니다.
    • 언어는 앱 언어를 변경합니다.
    • 데이터/저장소는 백업을 위해 앱 데이터를 내보내거나 가져옵니다.
    • 음악 모드는 박자(Beats)와 마디(Bars) 사이를 전환합니다.
    • 박자표는 마디당 박자 수를 선택합니다.

    재생 알림 컨트롤 사용

    재생 중에는 Android에 현재 BPM과 빠른 컨트롤이 포함된 미디어 알림이 표시됩니다. 이를 사용하여 재생을 중지하고, 템포를 내리거나 올리고, 앱으로 돌아가거나 종료할 수 있습니다.
